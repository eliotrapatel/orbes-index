# Faits du code pour les CGU

Ce document est la source des [conditions générales d'utilisation](terms.fr.md) ([version anglaise](terms.en.md)). Il dit, règle par règle, ce que fait réellement le service ORBES GENOME CODE (la vérification sur theorbes.com/verify, servie par verify.theorbes.com, et le compte ORBES), avec la constante et la ligne de code qui l'appliquent. Il est écrit pour l'avocat qui relit les CGU et pour l'équipe qui modifie le code.

- **Une règle, une ligne.** Chaque règle porte un identifiant (R01…), la valeur que le code applique, la constante exportée qui la fixe quand il y en a une, le fragment de code qui l'applique et la ligne où il se trouve (chemins relatifs à `genome/src/`). Quand une règle tient en plusieurs lignes voisines, la colonne cite la plage, et chaque fragment s'y trouve.
- **Ce que le code ne fait pas** (N1…) est établi lui aussi, au §10 : aucun e-mail hors de sa file, aucune réinitialisation sans code de récupération, aucun retour sur un transfert accepté, aucun appel à une boutique en ligne. Le §11 tient les conditions elles-mêmes : leur acceptation sous CREATE ACCOUNT et leur version publiée (J-06). Le §12 tient les sorties (P-R03) : l'inscription, les paliers, le tirage et sa graine publiée, puis l'accès anticipé (P-X02) ; le §13, le cercle des propriétaires (P-X01) ; le §14, les avantages des paliers (P-X04) ; le §15, le salon privé (P-X08) ; le §16, un modèle arrêté (P-R06) ; le §17, ORBES CARE (plan du 2026-10-15), qui remplace l'abonnement ORBES Care (P-M02) ; le §18, les LIVE RELEASES (plan du 2026-10-04) : l'annonce et ses étapes, la salle, la file à l'ouverture, le tour et son geste, la pièce tenue et ses options, PAY, la seconde chance, les gestes d'ORBES pendant la sortie, sa fin, et ce qui est enregistré ; le §19, les commandes de chaque canal (plan LIVE RELEASE+ du 2026-10-04) : leurs étapes, la pièce qu'elles tiennent ou font fabriquer, l'expédition, la livraison, l'annulation, le retour et la propriété reprise, les factures et les avoirs, l'acheteur, MY PIECES et l'export ; le §20, la salle d'après, la surprise, la participation et les segments dans l'accès, l'onglet PAST, la question d'après et l'activité par heure ; le §26, les deux garanties ORBES et leurs demandes (plan ORBES CARE du 2026-10-15) ; le §27, le rythme d'une LIVE RELEASE, une sortie réservée à des collectionneurs choisis, la réinitialisation par e-mail, la liste fondatrice et les e-mails (lot M1 du plan MACRO, décisions du 2026-10-20) ; le §28, les messages de la maison et WORN, la galerie des propriétaires (lot M2 du plan MACRO) ; le §29, les articles complémentaires, les tailles enregistrées comptées pour les commandes aux fournisseurs et THE SET (lot M3 du plan MACRO).
- **Le test** `genome/test/docs/terms-facts.test.ts` lit ces tableaux. Il recalcule chaque valeur depuis la constante exportée, vérifie que chaque fragment se trouve à la ligne citée, et contrôle chaque absence dans le code. Une modification du code qui change une règle, ou qui déplace la ligne qui l'applique, fait échouer le test (son message donne la nouvelle ligne) : on met à jour ce document, puis les CGU si la règle a changé.
- **Les CGU citent ces identifiants** à la fin de chaque article (la ligne *Code : …*). Le test vérifie que chaque règle est citée en français et en anglais, que l'article qui la cite donne sa valeur, et que les deux versions citent les mêmes règles, article par article.
- **Les valeurs sont celles de la production.** Deux réglages du serveur pourraient en changer une, `SESSION_TTL_ACCOUNT_HOURS` (R09) et `TRANSFER_ACCEPT_REQUIRE_PRODUCT` (R40) : le test vérifie que `deploy/vps/.env.example`, le modèle du serveur, les laisse en commentaire.

Ce qui relève d'une procédure humaine et non du code (la vérification d'identité avant un code de récupération, l'examen de la pièce avant de lever un vol, les motifs d'un verrouillage, l'examen d'une pièce renvoyée au titre d'une garantie et la décision qui le suit, l'écart de la seconde inscription d'une même personne à une sortie, la vente qui suit une place réservée, tirée ou réservée directement, celle qui suit une réservation confirmée d'une LIVE RELEASE, ou une demande du salon privé, le paiement qu'ORBES Client Services constate avant de marquer une commande PAID, la livraison et le retour d'une pièce) est listé dans la [note pour l'avocat](counsel-note.fr.md).
